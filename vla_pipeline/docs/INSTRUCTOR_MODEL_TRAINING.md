# 강사 모델 학습·배포 기록

학생 실행 기준 브랜치는 `instructor/runtime-conda-fixes`입니다.
대용량 가중치는 GitHub Releases에 두고, 이 브랜치에는 다운로드 명세·실행 코드·검증 범위를 보관합니다.
학생용 고정 명세는 `models/release_manifest_deadline_20261106.json`이며,
사용 방법은 저장소 루트의 [`research/3_colab_guide.md`](../../research/3_colab_guide.md)를 확인하세요.

## 학생에게 전달한 모델

| 모델 | 학습 자료·설정 | 확인한 범위 |
|---|---|---|
| VLM R5 | 기존372개+새 초기160개=532개. R3에서480업데이트, LR1e-5, 시각 인코더 고정, FP32 학습 가중치/BF16 연산 | Colab 고정132계획 입력: 목표쌍 F1 .9259, 형식131/132. 실제 운반 성공률 아님 |
| VLA motion7k | 성공 부분 시연181개·23,173프레임. 이전8k 모델에서 추가 학습한 8k 실행 중7k 저장본. 배치64, LR1e-4, expert-only, BF16 연산, chunk10/cache10 | 로컬 단일14/20·번호 선택3/20. Colab 빠른 점검 단일2/5·번호 선택1/5(다른 표본·정책 난수). 전체 정리60% 보장 아님 |

가중치와 학습 데이터 생성은 로컬 RTX3090Ti에서 처리했습니다.
Colab에서는 공개 ZIP 다운로드·SHA256 확인·GPU 추론만 수행합니다.
두 모델의 Release에는 추론에 필요한 설정·토크나이저·정규화 파일을 함께 넣었습니다.
VLA는 각 텐서의 저장 정밀도를 복원하며, 학습된 전체 가중치를 임의로 한 정밀도로 바꾸지 않습니다.

motion7k는 내부 XYZ를 다음 로봇 제어 목표 위치로 학습한 `absolute_position` 형식입니다.
실행기가 이를 기존 delta7로 변환합니다. 관측은 RGB 두 카메라·state16, 외부 행동은 action7입니다.
물체 정답 좌표를 신경망의 추론 입력으로 사용하지 않습니다.

## 이번 A/B/C 비교의 의미

`--shared-vla`를 지정하면 A/B/C 모두 동일한 `vla_hier`를 읽습니다.
A에는 전체 정리 지시와 공개 정리 규칙을 주고 VLM을 호출하지 않습니다.
B/C에는 같은 VLM이 만든 부분 운반 지시를 줍니다. C0/C1/C2는 각각 별도로 취합합니다.

이것은 **부분 작업을 학습한 동일 VLA에 VLM·루프를 추가한 비교**입니다.
전체 과제를 별도 학습한 A의 일반적 성능과는 구분합니다. 기존r1 A의0/10을
이번 공통 모델 A의 점수로 적지 않습니다. A의 실제 성능은 새로 측정해야 합니다.

## 이후 학습을 재현할 때

모델 폴더에는 추론 설정이 있고, 로컬 학습 출력에는 `launch_options.json`과
체크포인트별 설정이 있습니다. 원시 시연·optimizer·특징 캐시는 일반 Git에 올리지 않습니다.
원래 중간 모델과 시연이 필요한 정확한 재현은 강사 로컬 출력도 필요합니다.
다른 데이터로 시작하는 추가 파인튜닝은 별도 실험으로 기록합니다.

`scripts/train_vla.py`의 주요 옵션은 다음과 같습니다.

- `--base`: 학습 시작 체크포인트. 학생용 모델도 추가 학습의 시작점으로 사용할 수 있습니다.
- `--expert-only`: 기반 시각·언어 모델을 고정하고 행동 생성부를 학습합니다.
- `--train-vlm`, `--train-vision`: VLA 내부 언어망, 또는 시각 인코더까지 학습합니다. 상위 VLM 학습과 별개입니다.
- `--vision-cache`: 고정된 실제 RGB 특징을 재사용합니다. expert-only 학습에서만 사용합니다.
- `--frame-weights`: 같은 물리 프레임에 같은 추출 비중을 주는 강사 학습용 옵션입니다. 정렬된 A/B 데이터에서 동일한 배열·seed를 사용합니다.

원시 시연을 먼저 씬별 train/validation으로 나누고, 모델 선택에는 validation만 씁니다.
학생의 최종20개 테스트 씬을 학습·모델 선택에 쓰지 않습니다.
전체·부분 작업 데이터가 같은 물리 시연이어도 에피소드 경계와 미래 행동 패딩은 달라질 수 있습니다.

추가 학습 중인 후보는 고정 학생 명세에 자동 반영하지 않습니다.
새 모델을 배포하면 새 버전의 별도 실험 묶음에서 사용하고, 기존 결과와 섞지 않습니다.
