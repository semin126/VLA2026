# 여러분이 결정할 연구의 여섯 지점

설치·저장·모델 입출력 연결은 조교가 제공합니다. 여러분의 과제는 **질문을 선택하고, 비교를 설계하고, 결과를 설명하는 것**입니다. 아래 후보를 모두 수행하지 말고 핵심 질문 하나와 이를 확인할 확장 하나를 고르세요.

| 판단 지점 | 스스로 답할 질문 | 남길 기록 |
|---|---|---|
| 1. 문제 선택 | 파지 여유, 목적지 점유, 라벨 판독, 반복 실패 중 지금 가장 중요한 병목은 무엇인가? | 실패 영상 두 개와 원인 후보, 이 문제를 선택한 이유 |
| 2. 실행 가능성 | 보인다는 것과 집을 수 있다는 것은 어떻게 다른가? 놓을 자리는 어떻게 확인할까? | 검사 규칙·여유값과 그 이유, 검사 오류를 드러낼 배치 |
| 3. 행동 순서 | 목표 물체를 바로 옮길까, 방해물을 먼저 옮길까? 언제 추가 이동이 손해일까? | 순서 선택 규칙, 유리한 조건과 반례 |
| 4. 피드백 | 무엇을 실패로 볼까? 언제 다시 계획하고 언제 멈출까? | 관측 가능한 실패 기준, 같은 행동 재시도와의 차이 |
| 5. 검증 | 무엇과 같은 조건에서 비교해야 내 설명을 시험할 수 있을까? | 비교군·정보·예산·독립 배치·주지표·반증 조건 |
| 6. 해석과 다음 실험 | 예상과 다르면 어떤 설명들이 가능한가? | 경쟁 설명 둘과 이를 구분할 추가 실험 |

## 한 번의 수업에서 할 일

1. `notebooks/Final_project.ipynb`의 기본 A를 실행하고 영상과 로그를 찾습니다.
2. “어떤 조건에서 어떤 방법이 어떤 이유로 달라질 것인가?”를 세 문장으로 적습니다.
3. 코드 수정 전에 [워크시트](WORKSHEETS.md)에 비교 조건과 반대 결과를 적어 조교와 검토합니다.
4. `vlapipe/student_design.py`의 접근성, 다음 행동, 재계획 세 함수 중 필요한 부분을 구현합니다.
5. 작은 개발 장면에서 오류를 고친 뒤 조건을 고정하고 새 평가 장면으로 확인합니다.
6. 성능 수치와 함께 실패 영상 하나를 설명하고 다음 실험을 제안합니다.

추천 출발 질문은 **“출발지 접근성과 목적지 점유를 함께 고려하면 언제 미완료와 추가 이동이 줄어드는가?”**입니다. 목적지 여유가 많으면 효과가 작거나 검사 비용이 더 들 수 있다는 반대 예측도 시험하세요. 다른 질문을 선택해도 됩니다.

## 연구 결과로 세면 안 되는 것

- 1~2스텝 학습 성공을 충분히 학습된 로봇의 성능이라고 부르기.
- 동일 배치의 반복을 서로 다른 장면으로 세기.
- 재계획 조건에만 더 많은 정보·시도·시간을 주고 방법의 효과라고 해석하기.
- 성공한 시도만 남기고 실패를 완료율 분모에서 빼기.
- 평면 큐브 실험으로 실제 적층 택배의 안정성까지 해결했다고 말하기.
- 조교가 구현한 코드를 자신이 설계한 부분과 구분하지 않기.

자세한 원리·실험 설계·해석 방법은 [연구 안내서](STUDENT_RESEARCH_GUIDE.md)를 읽으세요. 막히면 RUN_ID와 오류 로그를 조교에게 전달하세요. 연구 판단이 막혔다면 시도한 규칙·증거·현재 가능한 설명을 함께 제시하세요.
