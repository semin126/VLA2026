# 보고서에 사용할 실험 방법 문장

로컬 NVIDIA GeForce RTX 3090 Ti에서 고정된 oneway·mutual 씬을 각각 5개씩 평가하였다.
각 계열에는 어질러진 큐브 수가 2·4·6·8·10개인 씬을 하나씩 포함했고,
동일한 씬·시드(42)에 대해 A·B·C1을 실행하여 총 30회 비교하였다.
실행당 제한은 120초, 운반 단위는 240스텝, 관측 간격은 60스텝이며 VLM 호출 한도는 12회였다.
모델은 VLM R5와 부분 작업 학습 VLA motion7k로 고정하였다.
A는 같은 VLA에 전체 과제 지시를 전달하고 VLM을 호출하지 않았으며,
B는 초기 계획 한 번, C1은 실패가 의심될 때 재계획하는 전략을 사용하였다.
최종 물체 정확도(ACC), 구역 macro F1, 시작 대비 ACC 변화, 전체 씬 완료 여부와 과제 시간을 기록하였다.
같은 씬의 A·B·C1은 짝지은 비교이며 계열별 독립 씬 수는 5개이다.
이는 학생 Colab 300초 실험과 별도로 수행한 120초 예비 실험이다.
초기 물리 상태·프롬프트와 첫 VLM 응답은 B/C1의 10쌍 모두 같았다.
실제 초기 VLM 입력 영상은 9쌍이 완전히 같았고 mutual scene_0050에서만 RGB 채널 값 2개가 각각 1/255 차이 났다. 이 렌더링 차이는 audit.json에 기록했으며 영상을 수정하거나 실험을 다시 골라 실행하지 않았다.
부분 작업으로 학습한 VLA에 전체 지시를 주는 A의 학습 분포 차이,
oneway의 90도 회전 큐브와 mutual의 막힘 방식 차이,
정답 좌표를 쓰는 D를 이용한 씬 선정 절차를 해석의 한계로 명시한다.
전체 정리 성공률이나 전략의 일반적인 우수성을 이 소규모 실험만으로 결론 내리지 않는다.

수치는 REPORT.md와 report_table.csv를 사용하고, 실행별 원본은 trial_metrics.csv와 trials/에 있다.
시간 열은 모델 로딩·영상 저장을 제외한 과제 시간이다. 정확한 총 소요 시간은 progress.json에 있다.
이 시간은 실행 종료까지의 시간이며 정리 성공까지의 시간이 아니다. 계획 소진으로 일찍 끝난 미완료 실행도 포함하므로, 짧은 시간만으로 효율이 높다고 해석하지 않는다.
압축 묶음에는 점수·계획·사건 로그·그림을 넣었다. MP4 영상과 전체 소스는 원본 실행 폴더에 보관한다.
